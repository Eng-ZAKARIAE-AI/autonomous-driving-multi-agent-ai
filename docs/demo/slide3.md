# Slide 3: Objectives

## Project Goals & Objectives

1.  **Modular Architecture:** Implement a decoupled system (Backend, Simulator, Frontend) for easier maintenance and deployment.
2.  **Multi-Modal Perception:** Combine visual (RGB) and kinematic (Vector) data for superior spatial awareness.
3.  **Advanced RL:** Leverage state-of-the-art algorithms like **SAC** (Soft Actor-Critic) and **PPO** for continuous vehicle control.
4.  **Real-Time Monitoring:** Provide a telemetry dashboard for live visualization of agent performance and internal states.
5.  **Safety & Efficiency:** Design reward functions that prioritize not just speed, but also lane keeping, progress, and passenger comfort (low jerk).
