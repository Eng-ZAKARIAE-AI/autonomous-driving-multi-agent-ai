# Slide 6: Technologies

## Technical Stack & Tools

- **Simulator:** CARLA 0.9.15 (Unreal Engine 4 based).
- **Core Language:** Python 3.11.
- **AI Framework:** PyTorch (Neural Networks), Gymnasium (RL Environment).
- **Backend/API:** FastAPI, WebSockets (Real-time Telemetry).
- **Frontend:** React.js, Tailwind CSS (Dashboard).
- **Infrastructure:** Docker, Docker Compose, NVIDIA Container Toolkit (GPU Acceleration).
- **Version Control:** Git.
