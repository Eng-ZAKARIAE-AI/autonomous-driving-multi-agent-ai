# Slide 7: Demonstration

## Performance in Action

### Training Highlights
- **Environment:** CARLA Town04 (Highway & Urban mix).
- **Scenario:** Navigate from Point A to Point B while maintaining speed and avoiding collisions.
- **Visuals:** The agent "sees" the world through a top-down or semantic-filtered camera view (processed to 84x84).

### Live Telemetry Dashboard
- Displays real-time steering angle, throttle intensity, and brake pressure.
- Visualizes cumulative reward trends and lane offset distance.
- Monitors vehicle health and connection status to the CARLA server.
