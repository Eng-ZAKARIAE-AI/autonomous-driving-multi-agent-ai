# Slide 9: Future Improvements

## Roadmap & Next Steps

### Phase 1: Advanced Perception
- Integration of **YOLOv8** for explicit object detection (cars, pedestrians, traffic lights).
- **Semantic Segmentation** masks to improve lane detection and obstacle avoidance.

### Phase 2: Safety Layers
- Implementation of **Control Barrier Functions (CBF)** as a safety shield to override dangerous RL actions.
- Rule-based emergency braking systems.

### Phase 3: Real-World Bridging
- **ROS Bridge** integration for potential deployment on physical hardware.
- Multi-agent coordination (V2V communication) for dense traffic scenarios.
